# SMART-SINKS synthetic benchmark assets

This repository publishes **125 distinct synthetic JSON assets** for the SMART-SINKS Agent–MCP research benchmark: 40 catalogue seed assets and 85 scenario publication assets. They are synthetic benchmark inputs, not field observations, calibrated measurements, or scientific estimates.

Each asset has six records across three synthetic site labels and two synthetic dates. Each record includes the variables named in its metadata, with explicit units or categories. The public base URL is `https://alqatf.github.io/smart-sinks-benchmark-assets/v3`.

The `source_index.json` lists every asset URL, provider DID, and SHA-256 hash. The corresponding execution suite, scoring oracle, generator, and hash lock remain in the SMART-SINKS research project. Earlier evaluation results must not be attributed to these revised assets without a new run.

All raw JSON URLs are publicly downloadable. EDC contracts govern transactions performed through EDC but cannot restrict direct downloads from this public repository. Numeric ranges are illustrative and deterministic; they are not an ecological simulation or evidence of observed peatland conditions.
